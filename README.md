\# Cloud Storage Management System



A cloud-based storage management system developed using \*\*Google Apps Script\*\*, designed to manage and organize user data efficiently with secure credential handling.

## 🔗 Live Demo
Check out the deployed app here: [Cloud Storage Web App](https://script.google.com/macros/s/AKfycbyQunLKMqeUEQKc72dYGgLWuOUjAJUz7fLfxBOiGNPAfYpNH6lJehmfpwJrAZv_KMEaFA/exec)



\## 🚀 Features

\- Cloud-native automation using Google Apps Script

\- User authentication logic (credentials stored securely using Script Properties)

\- Lightweight web interface using HTML

\- Secure handling of sensitive data (excluded from version control)

\- Version-controlled using Git and GitHub



\## 🛠️ Tech Stack

\- Google Apps Script

\- JavaScript

\- HTML

\- Git \& GitHub



\## 🔐 Security Note

Actual user credentials and sensitive configuration details are stored using \*\*Google Apps Script Properties\*\* and are \*\*not included in this repository\*\* for security reasons.



\## 📂 Project Structure

\- `Code.js` – Core backend logic written in Google Apps Script

\- `index.html` – Frontend interface

\- `appsscript.json` – Project configuration file

\- `.gitignore` – Excludes sensitive and unnecessary files



\## 🧑‍💻 How to Run

1\. Clone the repository

2\. Use `clasp` to push the project to Google Apps Script

3\. Configure Script Properties for credentials

4\. Deploy or test within the Apps Script environment
